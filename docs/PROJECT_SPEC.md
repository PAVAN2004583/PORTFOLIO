# Project Specification

This project is a full-stack portfolio website for an MCA student with a focus on cloud computing and modern software engineering. It includes a responsive public website, portfolio admin management, AI assistant, contact flow, and a secure backend API.

## Objectives
- Present a professional personal portfolio to recruiters and collaborators.
- Showcase projects, education, technical skills, and resume access.
- Support admin-managed portfolio updates through a secure dashboard.
- Collect contact messages and allow message management.
- Offer an AI assistant grounded in portfolio data rather than invented facts.

## Target Audience
- Hiring managers
- Universities and internship reviewers
- Technical recruiters
- Community collaborators
- Cloud and backend-focused teams

## User Experience
- Clean and professional design
- Responsive layout for desktop and mobile
- Easy navigation across major portfolio sections
- Clear calls to action for contact and resume access
- Accessible forms with validation and feedback
